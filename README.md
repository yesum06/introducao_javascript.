# 📚 Estudo:: Cadastro de Categorias e Usuários em JS

Simulador simples de cadastro para blog usando **JavaScript** para consolidar conceitos fundamentais de lógica e proporcionar o primeiro contato com a linguagem.

# 🚀 Prática

### 🏷️ Cadastro de Categorias

Pequeno simulador de cadastro para blog usando JS puro.

### 🔐 Login

Tela de login com alternância de tema claro/escuro utilizando `classList.toggle()`.

### 👥 Cadastro de Usuários

Aplicação CRUD desenvolvida em JavaScript puro para praticar armazenamento local e manipulação dinâmica de dados.

**Funcionalidades:**

* ➕ Cadastro de usuários;
* 📋 Listagem de usuários cadastrados;
* ✏️ Edição de registros;
* 🗑️ Exclusão de registros;
* 💾 Armazenamento de dados com `localStorage`.

## 🧠 Conceitos Aplicados

* 💬 `prompt()`, `alert()` e `confirm()`;
* 🔢 Conversão para `Number`;
* 🔁 Laço de repetição `for`;
* 🌿 Condicionais `if/else`;
* 🎯 Eventos com `addEventListener()`;
* 🖥️ Manipulação do DOM;
* 🔎 Seleção de elementos com `getElementById()`;
* 📝 Manipulação de conteúdo com `innerHTML`;
* 📥 Captura de valores com `.value`;
* 📦 Objetos JavaScript;
* 📚 Arrays e métodos de arrays;
* ➕ Inserção de elementos com `push()`;
* ➖ Remoção de elementos com `splice()`;
* 🔄 Percorrer listas com `forEach()`;
* 🧩 Template Strings (`` `${}` ``);
* ⚙️ Operador lógico `||`;
* 💾 Armazenamento local com `localStorage`;
* 🔄 Conversão de dados com `JSON.parse()` e `JSON.stringify()`;
* 🛠️ CRUD (Create, Read, Update e Delete);
* 🔗 Navegação entre páginas HTML.
